MarsOS 1.2 "Olympus"

A retro Linux covered in red Martian dust — based on Debian GNU/Linux 13.
Um Linux retrô com a poeira vermelha de Marte — base Debian GNU/Linux 13.

Getting started

Alt + Tabswitch windows

Ctrl + Alt + ← / →switch workspace (Olympus, Valles, Gale, Jezero)
Print Screenscreenshot (Alt: window, Shift: pick an area) → Pictures
